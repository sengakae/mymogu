# Moguween Night Market

A Halloween-themed web experience featuring a curated “night market” of minigames and media. Built with React and CSS, deployed on Vercel, and designed for quick, playful interactions during a seasonal event.

## Production

Live site: [moguween.vercel.app](https://moguween.vercel.app/)

## Features

- Themed Halloween microsite with responsive UI and smooth navigation (React + CSS)
- Embedded minigames built with Godot and Unity, presented as cohesive web experiences
- Deployed to Vercel with fast builds, preview environments, and edge caching
- Performance- and accessibility-minded implementation for mobile and desktop
- Visitor analytics tracked for demographics, traffic sources, engagement, and retention (~800–1,000 visitors during event)

## Tech Stack

- React, JavaScript, CSS
- Vercel (hosting & CI/CD)
- Godot and Unity (minigame builds)

## Development

Install dependencies and start the dev server:

```bash
npm install
npm start
```

Create a production build:

```bash
npm run build
```
